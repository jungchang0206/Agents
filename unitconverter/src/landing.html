🔁 Unit Converter Agent

An AGINT-compliant unit conversion service. No API key required. All conversions run locally in the Worker.

Tools

Tool Description
convert_length mm, cm, m, km, in, ft, yd, mi, nmi
convert_weight mg, g, kg, t, oz, lb, st, short_ton
convert_temperature celsius, fahrenheit, kelvin, rankine
convert_currency 20 currencies — fixed reference rates
convert_timezone Any IANA timezone pair
list_units List all supported units per category

Endpoints

  • GET /.well-known/agint/manifest.json
  • POST https://unitconverter.jungchang02062004.workers.dev/v1/mcp/tools/call

Example Requests

Length

POST /v1/mcp/tools/call
{ "tool": "convert_length", "arguments": { "value": 26.2, "from": "mi", "to": "km" } }

Weight

POST /v1/mcp/tools/call
{ "tool": "convert_weight", "arguments": { "value": 180, "from": "lb", "to": "kg" } }

Temperature

POST /v1/mcp/tools/call
{ "tool": "convert_temperature", "arguments": { "value": 100, "from": "celsius", "to": "fahrenheit" } }

Currency

POST /v1/mcp/tools/call
{ "tool": "convert_currency", "arguments": { "value": 500, "from": "USD", "to": "EUR" } }

Timezone

POST /v1/mcp/tools/call
{ "tool": "convert_timezone", "arguments": { "datetime": "2024-06-15T09:00:00", "from": "America/New_York", "to": "Asia/Tokyo" } }

List Units

POST /v1/mcp/tools/call
{ "tool": "list_units", "arguments": { "category": "currency" } }
