🃏 Flashcard Generator Agent

An AGINT-compliant flashcard service powered by Cloudflare Workers AI — no external API key required.

Tools

ToolDescription
generate_flashcardsTurn study notes into Q&A flashcard pairs
generate_quizConvert flashcards into a multiple-choice quiz
simplify_cardRewrite a hard card in simpler language

Endpoints

  • GET /.well-known/agint/manifest.json
  • POST /v1/mcp/tools/call

Example Requests

Generate flashcards

POST /v1/mcp/tools/call
{
  "tool": "generate_flashcards",
  "arguments": {
    "text": "Photosynthesis is the process by which plants use sunlight, water, and CO2 to produce glucose and oxygen.",
    "count": 3,
    "difficulty": "easy",
    "subject": "Biology"
  }
}

Generate quiz

POST /v1/mcp/tools/call
{
  "tool": "generate_quiz",
  "arguments": {
    "flashcards": [
      { "question": "What do plants absorb during photosynthesis?", "answer": "Sunlight, water, and CO2" }
    ],
    "count": 1
  }
}

Simplify card

POST /v1/mcp/tools/call
{
  "tool": "simplify_card",
  "arguments": {
    "question": "What is the role of NADPH in the Calvin cycle?",
    "answer": "NADPH provides the reducing power needed to convert CO2 into G3P during carbon fixation.",
    "level": "beginner"
  }
}
