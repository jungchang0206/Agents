📝 Word Counter Agent

An AGINT-compliant word counting service. No API key required.

Tool

count_words — returns word count, character count, character count without spaces, sentence count, and paragraph count for any input text.

Endpoints

  • GET /.well-known/agint/manifest.json
  • POST https://wordcounter.jungchang02062004.workers.dev/v1/mcp/tools/call

Example Request

POST /v1/mcp/tools/call
{
  "tool": "count_words",
  "arguments": {
    "text": "Hello world! This is a test sentence.\n\nAnd a second paragraph."
  }
}

Example Response

{
  "word_count": 12,
  "character_count": 62,
  "character_count_no_spaces": 52,
  "sentence_count": 3,
  "paragraph_count": 2,
  "source": "word_counter"
}
