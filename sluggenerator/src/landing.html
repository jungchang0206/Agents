Slug Generator Agent

This is an AGINT-compliant service that generates URL-friendly slugs from text.

Features:

  • Generate clean, SEO-friendly slugs
  • Customizable separators (-, _, etc.)
  • Optional stopword removal
  • Maximum length constraints
  • Batch processing support
  • Accented character handling

Endpoints:

Capabilities Manifest — Service discovery endpoint
POST /v1/mcp/tools/call — Call slug generator tools

Available Tools:

1. generate_slug

Convert a single text to a slug:

POST /v1/mcp/tools/call
{
  "tool": "generate_slug",
  "arguments": {
    "text": "Hello World! This is a test.",
    "separator": "-",
    "max_length": 30,
    "lowercase": true,
    "remove_stopwords": false
  }
}

Response:

{
  "slug": "hello-world-this-is-a-test",
  "original_text": "Hello World! This is a test.",
  "metadata": {
    "word_count": 6,
    "original_length": 24,
    "slug_length": 24,
    "separator_used": "-",
    "truncated": false
  },
  "source": "slug_generator"
}

2. batch_generate_slugs

Process multiple texts at once:

POST /v1/mcp/tools/call
{
  "tool": "batch_generate_slugs",
  "arguments": {
    "texts": [
      "Hello World!",
      "Café & Restaurant",
      "Product Review 2024"
    ],
    "separator": "_"
  }
}

Example Transformations:

  • "Hello World!" → "hello-world"
  • "Café & Restaurant" → "cafe-restaurant"
  • "The Quick Brown Fox" (with stopwords) → "quick-brown-fox"
  • "Product Review 2024" → "product-review-2024"
