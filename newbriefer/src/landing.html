📰 News Briefer Agent

An AGINT-compliant news briefing service powered by NewsAPI.org.

Endpoints

  • GET /.well-known/agint/manifest.json — Capabilities manifest
  • POST https://{{hostname}}/v1/mcp/tools/call — Invoke a tool

Tool: get_news_briefing

POST https://{{hostname}}/v1/mcp/tools/call
Content-Type: application/json

{
  "tool": "get_news_briefing",
  "arguments": {
    "category": "technology",
    "country": "us",
    "count": 5
  }
}

Tool: get_news_briefing (keyword search)

POST https://{{hostname}}/v1/mcp/tools/call
Content-Type: application/json

{
  "tool": "get_news_briefing",
  "arguments": {
    "query": "artificial intelligence",
    "count": 3
  }
}

Tool: summarize_article

POST https://{{hostname}}/v1/mcp/tools/call
Content-Type: application/json

{
  "tool": "summarize_article",
  "arguments": {
    "url": "https://example.com/some-news-article",
    "max_sentences": 4
  }
}
